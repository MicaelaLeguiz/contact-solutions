# ¿Cuánto automatizar? Una decisión de negocio respaldada por datos

## Descripción
Proyecto de portafolio de análisis de datos que evalúa el impacto operativo y comercial de la incorporación de agentes de IA en una operación de ventas telefónicas, bajo un modelo híbrido de agentes humanos e IA. El objetivo es generar recomendaciones basadas en evidencia para orientar la estrategia de expansión del modelo.

## Caso de negocio
Contact Solutions es una empresa ficticia de contact center. Uno de sus clientes del sector turístico, Global Experience, implementó durante 3 meses un esquema mixto de atención (141 agentes humanos y 9 agentes de IA) para la venta telefónica de paquetes vacacionales. El proyecto analiza esos datos para determinar la estrategia de incorporación de IA que maximiza el beneficio esperado, respetando un presupuesto mensual de USD 380.000 y un CSAT mínimo de 85%.

## Objetivos
- Caracterizar el desempeño actual de la operación.
- Comparar estadísticamente el desempeño de agentes humanos y agentes de IA.
- Proponer una estrategia de incorporación gradual basada en evidencia cuantitativa y un modelo de optimización.

## Herramientas
SQL (SQLite), Python (Pandas, estadística descriptiva e inferencial), Power BI.
